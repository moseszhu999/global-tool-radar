# ToolRadar Today Discovery Web v1

## Purpose

Make the default ToolRadar page understandable before exposing technical operations details.

The page answers four questions in plain Chinese:

1. how much public data was captured;
2. which current signals are growing;
3. why each signal may deserve research;
4. what the evidence still cannot prove.

## Surface ownership

- `/` is the simple Today Discovery page.
- `/workspace.html` preserves the existing evidence-oriented operator workspace.
- `apps/web/data/today-brief.json` is a source-bound public snapshot, not a new database owner.

## Boundaries

- momentum is not a final product or publishing decision;
- channel discussion does not prove product ownership;
- missing numbers are never displayed as zero;
- no source video, captions, comments, or user data are downloaded;
- no automatic publication is enabled;
- the current 3.237-hour interval remains `METRIC_CONFIRMATION_REQUIRED`.
