# ToolRadar Video Production Case v1

## Business purpose

Close the first missing business segment:

```text
confirmed signal
→ source-bound research evidence
→ Topic Brief
→ complete original voiceover script
→ human script review
```

This is not yet the finished-video or publishing milestone. It creates the canonical object that later storyboard, asset, render, QA, publication, and performance receipts attach to.

## Canonical object

`toolradar.video-production-case.v1` owns:

- source signal identity and official source URL;
- Topic Brief, audience, angle, promise, claim boundary, and non-claims;
- immutable research evidence references;
- a complete original Chinese voiceover script;
- Douyin and Bilibili title/description/tag drafts;
- rights, security, test-evidence, and human-review gates;
- the next milestone: `STORYBOARD_AND_ASSET_MANIFEST`.

## First real case

The first case uses `Introducing Replit Design` because the repository already contains both:

1. a confirmed official-channel momentum signal; and
2. a real independent product test showing that Design Canvas produced desktop and 390px designs in about three minutes, while Build still had no previewable artifact.

The generated script therefore says that design exploration passed but production delivery remains unproven. It does not claim country popularity, product adoption, direct production-code delivery, or universal pricing/credit behavior.

## Commands

```bash
npm run production:case:replit
npm run check
npm test
```

The CLI can also build another case from a compatible JSON input:

```bash
node apps/worker/src/build-video-production-case.mjs \
  --input path/to/input.json \
  --output path/to/output.json
```

## Hard boundaries

- no source-video download or reuse;
- no unsupported factual claim;
- no automatic publication;
- no publication before human script, rights, fact, and platform-spec review;
- missing evidence remains missing rather than being converted into promotional copy.
