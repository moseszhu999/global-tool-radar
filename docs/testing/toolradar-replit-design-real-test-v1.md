# ToolRadar Replit Design Real Test v1

## Purpose

Advance the first Stage 4 shortlist candidate into a reproducible Stage 5 real-product test without claiming success before a human uses the product.

## Evidence boundary

The YouTube signal proves only that the Replit official video `Introducing Replit Design` grew by 1,500 public views over 6.455 hours and outpaced the measured same-channel baseline. It does not prove country popularity, product adoption, or product quality.

## Human boundary

The only unavoidable human action is authenticating to Replit in a normal web browser. The test must not:

- create or purchase a paid plan;
- connect external accounts;
- upload secrets or sensitive data;
- create a database;
- publish a deployment;
- treat missing observations as passes.

## Standard run

1. Record the plan, visible credits, and start time.
2. Submit the canonical Chinese prompt once in Design Canvas.
3. Record time to the first complete design.
4. Grade the untouched first result against ten checks.
5. Perform exactly three direct Visual Editor changes: headline, accent color, and card spacing.
6. Check the 390px mobile layout.
7. Export the local `toolradar.test-receipt.v1` JSON.

## Promotion

Only a human receipt with an explicit decision may promote the candidate:

- `PROCEED_TO_SCRIPT`
- `WATCH_AND_RETEST`
- `REJECT`

No page view, button click, account creation, or incomplete checklist is a product-quality result.
